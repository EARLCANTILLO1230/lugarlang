Key Transport Policies

Tabang Pangbyahe Program
A DOTr‑Cebu Provincial initiative subsidising low‑demand routes to prevent stranding. Vehicles must have GPS linked to LGU command centres.

PUV Modernisation
Only consolidated cooperatives are issued franchises. Traditional jeepneys allowed only if part of a cooperative transitioning to Euro‑4 / electric fleets.
